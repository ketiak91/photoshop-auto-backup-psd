# Changelog

## 1.0.0 - 2026-09-29

Initial public release.

- Automatic save of the active Photoshop document.
- First-time Save As support for Untitled documents.
- Two-slot BU1 / BU2 rotating backup system.
- Older-backup replacement based on file modification time.
- Backup-of-backup safety check.
- Layered PSD backup output.
- Native Photoshop save with fallback save handling.
- No external `.atn` action required.
